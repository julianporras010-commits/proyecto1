# Sofia — Mi niña hermosa 💗

Proyecto romántico creado con React + Vite.

## Ejecutar
1. Instala Node.js (LTS).
2. Abre una terminal en esta carpeta.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev` y abre la URL local que indique Vite.

## Personalización
- Los fondos y recursos están en `public/`.
- Las tres fotos de recuerdos están en `public/recuerdo-*.jpg`.
- El fragmento musical está en `public/aquel-napzzzz-fragmento.mp3`. Empieza en 3:53 de la canción subida y llega hasta el final. La reproducción comienza solo cuando se pulsa el botón de música.
- Los textos y la fecha especial se configuran en `src/main.jsx`.
